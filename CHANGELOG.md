# Changelog

- 2026-10-19: `latex-memo` `scripts/redline.py` decodes the TeX engine's output with
  `errors="replace"`. pdflatex wraps its terminal lines at a fixed byte count, which can
  split a UTF-8 character, and the strict decode stopped the redline of a long memo.
- 2026-10-18: `latex-memo` requires a redline with every release after the
  first, `memo-NNN-redline.pdf` beside the PDF, against the memo as last
  merged to main. New `scripts/redline.py` (with tests) makes it: latexdiff
  (`--type=UNDERLINE --subtype=SAFE`) of the old and new source, built in a
  copy of the new memo directory, with a note naming both commits; `--fetch`
  downloads a pinned latexdiff 1.3.4 and checks its SHA-256. The skill says
  what the markup does not cover (figures, generated tables, number macros).
- 2026-10-10: `latex-memo` restores "use one version of each input", with its
  step-6 check (search the script for superseded version strings). It was added
  in the EIGSEP copy after the move and was missing here. The `<skills>` note
  now follows the list of project settings instead of splitting it.
- 2026-10-10: moved out of the specred workspace into its own repository, with
  history. Added `install.py` (Claude Code, Codex and Antigravity; project or
  user scope; copies record their commit and are protected from overwriting
  once edited), Claude Code and Codex plugin marketplaces generated by
  `tools/build.py`, and CI. Script paths in skills are now written
  `<skills>/<name>/scripts/...`, and cross-skill script use makes a skill a
  requirement.
- 2026-10-10: `spectral-analysis` adds `scripts/flag_cover.py` (with tests).
  It provides an exact separable row-and-column cover by min-cut, a greedy
  cover with K masks, and `FilterBank`, which reuses one DPSS projector per
  mask. On one native-resolution HERA file, 718 distinct masks reduce to 8 at
  0.37% extra flagging.
- 2026-10-10: new `spectral-analysis`. Windows and sidelobe levels, ringing from
  FFT-domain masks, flag gaps as holes in the window, scattering of bright
  power by a mask that varies along the fitted axis, and broadcasting flags so
  one DPSS filter is reused across an axis; with a four-step check for faint
  features.
- 2026-10-09: `21cm-analysis` adds "show that a null differs from the model
  before scoring against it". Three nulls for a HERA coupling fit (delay sign
  flip, delay permutation, 60° rotation) reproduced the predicted signal
  because of the array's symmetry.
- 2026-10-08: installed in specred. `.claude/skills` and `.agents/skills`
  link here. `memo-rebuild` was EIGSEP-specific (paths, campaign variables,
  `make_products.py`, pdflatex), so its steps are now the portable `latex-memo`
  (which absorbed specred's memo build and figure rules), and project settings
  go in `AGENTS.md` § Memos. `latex-memo` adds: memo numbering, a provenance
  record that includes separately versioned packages, and a check for running
  jobs before moving a memo directory. `latex-audit` now points to
  `latex-memo`.

- 2026-10-07: rules and tools carried over from the BLOOM-21cm SMEX proposal.
  New `technical-prose`, `latex-audit` (with `latex_audit.py`) and
  `latex-page-fit` (with `pdf_short_lines.py`). `21cm-analysis`: median flags
  past 50% occupancy, simulation results tied to their configuration, derived
  rather than typed numbers, linearised margins, crediting fixes.
  `21cm-figures`: printed text size, with `print_fonts.py`, `textfit.py` and
  `pdf_min_font.py`. `memo-rebuild` runs `latex_audit.py` in step 6. Added the
  `.agents/skills` symlink.

- 2026-10-07: rules from the memo 008 work. `21cm-analysis`: index by coordinate,
  name direction frames, check results with and without a mask, name degenerate
  columns, equal-freedom alternatives, one-variable controls. `21cm-figures`:
  compare models in observing coordinates with data, show a test's decision
  region and counts, show measurements against raw data, check the rendered page.
  `memo-rebuild`: branch-only products and a merge fallback.

- 2026-10-07: added `21cm-analysis` and `21cm-figures`, portable to other
  21-cm projects: Aaron's plotting notes plus the general rules that were in
  `AGENTS.md` § Analysis methodology, which now points to them and keeps only
  the EIGSEP lessons.
- 2026-10-07: added `memo-rebuild`, the steps memos 003-006 each repeated
  (clean-tree regeneration, numbers diff, PDF text check, merge on Aaron's OK).
